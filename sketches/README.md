- L23：城市长卷里只有同一个男主反复找寻；无女主、无女主剪影或标记。三张过程帧显示从邮局街区到站口再折返另一街区，完整动作可读性留到连续预览验收。

- E2／E3：夜色分岔路，男主持续左行、女主持续右行，间距越来越大，不再围着同一堵墙靠近。
- 夜景：站台、第二轮电车／画廊、末段拱廊与分岔路使用墨蓝绿、灰青纸片、暖黄窗灯；回忆和想象保持暖亮，避免全片单一米黄色。不用紫色渐变、霓虹或发光描边。

## 信纸结尾的约定

原曲完整播放。信纸从最后强重音附近的E4进入，后续实际正文一行一行显现；歌曲结束时画面继续保留。

```text
完整阅读停留开始 = max(歌曲结束时间, 最后一行完全显现时间)
视频结束时间 = 完整阅读停留开始 + 30秒
```

只有用户提供正文后才计算行数、阅读速度、分页及最终片长。目前只确认视觉留白，不展示假正文、不展示示例称呼或虚构落款。曲终后默认不自行循环背景音乐。配置见 `../ending-letter.json`，正文为null，不能把本批空白草图误当成最终片尾输出。

## 草图与成片的边界

- 所有螃蟹直接调用同一个 `../character.js`，没有重画或修改已确认造型。
- 本批是原生Canvas 2D纸艺关键帧：独立纸片、暖白边、纸纹、投影均由代码绘制，未使用图像生成模型。
- 静态图只验证构图、角色关系、环境遮挡、真实／回忆／想象辨识与信纸留白；不宣称已验证整个动作、转场或音画同步。
- 无歌词字幕烧入单帧原图；L39／L40的“1000天”是用户授权的场景文字，属于例外。总览中画框外的镜号、时间、歌词是审阅标签，不进入MV画面。
- 寄信草图加入邮筒旁台阶，让小螃蟹站位、钳端信封与投信口高度成立。完整投递的松钳／脱手过程仍需后续动画制作。
- L28／L32／L39等情绪重点放大角色；L41–L43在同一拱廊完成一次明确的环境遮挡事件，区别于前面街角的普通擦肩。
- 这一阶段未创建HyperFrames整片工程。草图确认后再接入HyperFrames并补连续动作，不从静态图数量推断动画已经完成。

## 复现

```powershell
.\.conda\mv\python.exe render_storyboard_sketches.py
# 只改过某几镜时，重画指定镜头并重建总览：
.\.conda\mv\python.exe render_storyboard_sketches.py --only L01 L02
```

`paper.js`提供纸片与环境道具；`scenes.js`保留基础构图，`revisions.js`通过统一入口实现v3城市寻找、云朵、夜景与缘尽错过。两者都属于当前草图源，移植时不能漏掉revisions.js。当前不是完整MV动画引擎。渲染器使用本地Chrome和已安装Conda依赖，无需联网。
