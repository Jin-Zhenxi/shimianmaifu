# 多歌曲导入与执行说明（2026-10-28）

新增首次打开的歌曲导入窗口：本机文件选择、可编辑歌名、可选 TXT/LRC/SRT 辅助歌词。新歌曲从空大纲和待制作卡片开始；保留旧歌曲，提供歌曲切换、音频试听和歌词查看。

音频和辅助歌词存入 workflow/songs/<UUID>/，prompt 记录输入路径。上传内容仅发给本机后台；音频不直接发给 DeepSeek 文本接口。模型上下文使用本次歌曲的音频路径与歌词，不自动注入旧歌曲的阶段读取文件。歌词识别和对齐仍依赖本地工具，缺少条件必须报告受阻。

界面明确：上传只导入、保存只写文件、聊天只打磨卡片；点击开始才调用 DeepSeek，通过工具循环执行当前阶段。完成或确认后切到下一卡，不自动启动下一步。制作代码工程仍共用，不能把旧歌时间轴和旧音轨用于新歌。

验证：17 项 node:test 通过；隔离根目录的真实 Chrome 浏览器检查通过（未调用真实 API）。覆盖无歌词和 LRC 两种上传、文件名自动填写、歌曲切换、音频 Range 请求、跨歌曲输入访问拒绝、重启恢复、错误输入拒绝、移动端布局、无浏览器异常。UI 报告：workbench-song-import-ui.json。

截图：workflow/previews/workbench-song-import-desktop.png、workbench-song-library-desktop.png、workbench-song-import-mobile.png。已检查桌面及移动截图，并修正大纲输入框的移动端宽度。
